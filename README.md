# TypeMaster

A browser typing game with chapters, lessons, boss battles, and free practice. Progress is stored in the browser.

## Preview

Open `index.html` in a modern browser. Start with **Continue Journey**, choose a chapter, or use **Free Practice**. No build, account, or backend is required.

The game includes WPM and accuracy tracking, a chapter progression system, battle effects, and a keyboard display. Local storage holds the player's progress; clearing browser data resets it.
